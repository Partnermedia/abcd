# Superseded

Intents killed by reclassification or absorption — folded into a larger intent or
replaced by a stricter successor. Each file records `superseded_by: <handle>` (the
successor — a later intent, or the ADR that redecided the question the intent
rested on) and `kind_at_supersession: <original-kind>` (the shape it had when
retired). The successor names the intent back in its own `supersedes`, and
`record_schema` blocks a supersession declared from one side only. Files here are preserved as historical record and never deleted.

See the [intents index](../README.md) for the corpus listing and the
[intent surface contract](../../brief/04-surfaces/05-intent.md) for the full
lifecycle.
