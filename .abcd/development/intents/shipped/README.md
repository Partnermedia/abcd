# Shipped

Capabilities built in Go, moved here as their linked specs close.

An intent moves here when its linked spec closes; the close hook emits an OWED
review receipt into each file's "Audit Notes" section, which `intent-auditor`
later replaces with the per-criterion verdicts and three-bucket prose audit
comparing delivered reality to the press release.
Bundle members move here together when their shared spec closes.

See the [intents index](../README.md) for the corpus listing and the
[intent surface contract](../../brief/04-surfaces/05-intent.md) for the full
lifecycle.
